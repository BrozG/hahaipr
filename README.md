# LEDCS e-Sewa (prototype)

Clickable prototype of the **Live Events Development Cell Sikkim (LEDCS) e-Sewa** portal, IPR Department, Government of Sikkim.

**Live demo:** http://skillsmdwiki.me/hahaipr/

Static HTML/CSS/JS with no backend. All data is sample data and stays in the browser (use "Reset demo data" in the footer). Payments, logins and SMS / WhatsApp / Email alerts are simulated.

**Demo flow:** Permission → Apply Online → add locations to the cart → pay → Dashboard: log in as Additional Director → Secretary → AD → departments → AD issues the permission letter.
