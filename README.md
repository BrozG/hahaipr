# Sikkim Film Connect: Single Window Facilitation Portal (E-SEWA) (prototype)

Clickable prototype of **Sikkim Film Connect**, the single window portal of the Sikkim Live Events and Film Shooting Facilitation Cell, IPR Department, Government of Sikkim.

Static HTML/CSS/JS with no backend. All data is sample data and stays in the browser (use "Reset demo data" in the footer). Payments, logins and SMS / WhatsApp / Email alerts are simulated.

**Demo flow:** Apply Online → Shooting Permission (or Live Event Permission) → Online Application → choose locations → fee summary → pay → Application No. and acknowledgement. Then Dashboard: log in as Additional Director → Secretary → AD → departments → AD issues the consolidated permission. Files past their Clause 23 timeline are escalated to the Secretary (State Nodal Officer) automatically.
